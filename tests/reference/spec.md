# x402 Sentinel 可靠度分數規格（純文字，供獨立實作）

## 資料模型
- 每個被追蹤的 subject（以太坊地址）有一份「檢查歷史」，是一串 0/1：1 = 該次檢查通過，0 = 失敗。
- 歷史以「最新在前」排列，最多保留 W = 20 筆。

## 記錄一次檢查
1. 把本次結果（通過 = 1，失敗 = 0）放到歷史最前面。
2. 若歷史超過 W 筆，只保留最新的 W 筆（丟掉最舊的）。
3. 以更新後的歷史計算分數。

## 分數
- total = 歷史筆數（0 到 20）。passes = 其中 1 的個數。
- 分數 = (passes + 1) / (total + 2) * 100，四捨五入到整數，.5 一律往上（round half up，不是銀行家取整）。
- 整數實作：score = (200*(passes+1) + (total+2)) // (2*(total+2))。
- 沒有額外上下限夾制。分數範圍由公式自然決定。

## 推論（可用來做 sanity check）
- total = 0 時分數為 50。
- total = 1：通過 67，失敗 33。
- total = 20：全過 95，全敗 5。
- 分數只取決於 (total, passes)，與 0/1 的排列順序無關；順序只影響哪些筆會在超過 W 時被丟掉。

## 唯讀評分
- 不新增任何結果，直接對現有歷史套用「分數」一節的公式。

## 不在範圍內
- 何謂「通過」的判定（是否解析出非零 payTo）、探測、鏈上寫入、Redis 以外的儲存。
